# Glosario

#recontool #glosario

Relacionado: [[../Indice|Índice]]

---

| Término | Significado en ReconTool |
|---------|--------------------------|
| **ReconTool** | Nombre del proyecto; API + UI de reconocimiento. |
| **bovrecon** | Bóveda Obsidian con la documentación lógica del proyecto. |
| **Target** | IP o hostname a escanear (campo `target`). |
| **Pipeline** | Secuencia nmap → enrich CVE → IA ([[../03-Backend/Pipeline-de-escaneo]]). |
| **cve_findings** | Lista unificada de CVEs (local + NVD) por puerto. |
| **ai_analysis** | Bloque JSON con vectores sugeridos por la IA. |
| **NVD** | National Vulnerability Database (API pública de CVEs). |
| **Ollama** | Runtime local de modelos LLM; alternativa a OpenAI en Kali. |
| **HTB** | Hack The Box; entorno lab autorizado de referencia. |
| **Shodan-like** | UI de búsqueda por IP; no implica indexación global. |

---

## Siglas técnicas

- **CVE**: Common Vulnerabilities and Exposures.
- **CVSS**: Puntuación de severidad.
- **OSINT / recon**: recopilación pasiva/activa de información expuesta.
